# Market Site Working Directory

This directory is for market website working content and local caching before pushing to the live GitHub Pages repo at ~/projects/blueearthcommunitymarket.

## Structure
- Working drafts and content development
- Local copies of updated files before deployment
- Assets and images for the market site

## Deployment  
Content here gets refined and then pushed to ~/projects/blueearthcommunitymarket → blueearthcommunitymarket.com via GitHub Pages.
